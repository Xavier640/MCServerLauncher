# MCServerLauncher
This is my personal project that started from a crazy idea. It's made 100% in C#, and it's a tool that helps manage and create minecraft servers easier.

# Why am i doing this?
🅾️ne day i decided to create a minecraft 
server of my own, and it took me a few hours. While doing it i learned a lot about how to setup a server, how to check logs, how to make services
in linux, and stuff like that. Then i thought, what if i don't want t do all this stuff? What if i want for this to simply be a UI as simple and as easy
to understand as the minecraft launcher? So here i am, writing this readme.md for everyone to know what this project is and why i'm doing it.

You can download the tool using this link and the guide in the description: https://github.com/Xavier640/MCServerLauncher/releases/tag/v1.0.0

# Important!
Requires a Playit.gg account, agent and a tunnel attached to the respective agent!
